# 陀螺仪鼠标 AirMouse

把手机变成电脑的鼠标 + 键盘：转动手机移动光标，触摸板负责点击/滚动，自带软键盘可以直接敲字。
电脑端**不需要装任何软件**（蓝牙 HID 模式）。

- 包名：`com.airmouse.gyro`
- 版本：手机端 `1.1.18`（versionCode 77）/ 电脑端 `1.1.10`（两端版本号各自独立，见 `update.json` 里的 `apk` / `server`）
- 产物：`dist/AirMouse-1.1.18.apk`（已签名，直接装）+ `dist/AirMouseSetup.exe`（电脑端安装程序，内嵌接收端）；发给别人直接给 `dist/AirMouse-1.1.18-发送包.zip`
- 最低系统：Android 9（API 28，蓝牙 HID 的起点）；实测 Redmi 23113RKC6C / HyperOS 3（Android 16）、OPPO PKT110 / ColorOS（Android 17）
- **要改代码或部署到新机器，看 [HANDOFF.md](HANDOFF.md)**（架构、构建环境、调试开关、踩过的坑都在里面）

---

**界面最上面一排**（v2.3 起）：`［蓝牙 ▾］［陀螺仪 关 ▾］［开关］`

- 左边那个下拉 = **连接方式**：点一下，按钮下面直接摊开「蓝牙 HID / WiFi / USB」，选中的那行带 ✓。
- 中间那个下拉 = **陀螺仪**：关 / 相对 / 射线，同样贴着按钮往下摊开。
- 右边那个 = **总开关**：打开才开始控电脑。

三条连接路径：

| | 蓝牙 HID | WiFi | USB |
|---|---|---|---|
| 电脑端 | 零安装，系统蓝牙就能认 | 要跑 `pc/airmouse_server.py` | 同样要跑接收端，但**不用填 IP** |
| 怎么连 | 配对一次，之后自动重连 | 手机填电脑局域网 IP | 插上数据线就行（接收端自动 `adb reverse`） |
| 地址 | 蓝牙设备名 `AirMouse-机型` | 如 `192.168.1.51:47777` | `127.0.0.1:47777` |
| 打字 | 只能英文/数字/符号 | **能打中文** | **能打中文** |
| 适合 | 日常无线用、演示翻页 | 有 WiFi、想无线又打中文 | 电脑蓝牙坏/没 WiFi/要最稳的链路 |

状态栏会写明当前走的是哪条路，例如「已连接 / 蓝牙 · QQDESKTOP」「已连接 / WiFi · 192.168.1.51:47777」「已连接 / USB · 127.0.0.1:47777」。

> **USB 模式不是「USB 网卡」**：手机的 `127.0.0.1:47777` 是接收端用 `adb reverse` 隧道转过来的。
> 所以第一次插线要允许「USB 调试」，接收端日志里出现 `[+] USB 通道已就绪 <序列号>` 就通了。
> 连不上时点状态栏看原因，或手动执行 `adb reverse tcp:47777 tcp:47777`。

> **总开关（重要）**：App 每次打开都默认关着，这时候它完全不碰电脑——蓝牙不断开、
> 网络不连、触摸板也不发指令，你可以放心用真鼠标。要用手机当鼠标时把右上角开关打开，
> 它才会连上电脑；用完关掉，电脑那边的手机鼠标立刻消失，不会再和你手里的真鼠标抢指针。

## 二、蓝牙 HID 模式（推荐）

**第一次**（手机 ↔ 电脑配对）：

1. 手机打开 App，连接方式选「蓝牙 HID」，状态显示 `HID 就绪` 说明 HID 服务已注册好。
2. 点状态栏 → 「让电脑发现本机（300 秒）」→ 系统弹窗点「允许」。
3. 电脑：`设置 → 蓝牙和设备 → 添加设备 → 蓝牙`，列表里找到 **AirMouse-机型**（例如 `AirMouse-PKT110`），点它配对。
   - 名字带机型是为了两台手机都能用时能分清：红米是 `AirMouse-23113RKC6C`，OPPO 是 `AirMouse-PKT110`。
4. 手机状态从 `HID 就绪` 变成绿色 `已连接 xxx` 就好了。

**以后**：打开 App 会自动连回上次那台电脑（找已配对的「电脑类」设备），不用再点。

**换设备**：点状态栏 → 选列表里的「连接：xxx」。

**装到第二台手机**（实测红米 HyperOS 3 + OPPO ColorOS / Android 17 都能用）：
- 直接装同一个 APK，无需改配置；每台手机自己记自己的设置（模式、IP、上次连的电脑）。
- OPPO / ColorOS 侧边加载：文件管理器里点开 APK，弹「未经安全检测」选「继续安装」；
  被手机管家拦就选「仍要安装」。用 `adb install` 一般直接成功。
- 两台手机可以同时连同一台电脑（服务端是多线程的），但**同时动会很乱**，平时只用一台。

注意：
- 电脑上的蓝牙要开着（耳机被手机占用时不影响 HID）。
- 电脑如果搜不到，多半是手机不在可发现状态，重新点一次「让电脑发现本机」。
- 想彻底断开：手机系统蓝牙里取消配对，或 App 切到别的模式。

## 三、WiFi 模式 / USB 模式

两条路都靠 PC 端这个接收端：WiFi 走网络，USB 走 `adb reverse` 隧道。

**电脑端（推荐：双击 exe，免安装、不要 Python）**

```
dist\AirMouseServer.exe
```

- 单文件 WinForms 程序（Win10/11 自带 .NET Framework 4，不用另装运行时），带托盘图标、本机 IP、日志、开机自启开关、复制 IP、一键「放行防火墙」。
- 和 `airmouse_server.py` **协议完全一致**（`m/a/b/w/k/s` 六种指令、绝对定位、中文 `KEYEVENTF_UNICODE`、adb reverse 自动通道），可以互换，但**不要同时开**（端口 47777 冲突，exe 会提示被占用）。
- 第一次运行 Windows 会拦两下：SmartScreen（「更多信息 → 仍要运行」）和防火墙（勾专用网络 → 允许）。这两个弹窗都在安全桌面上，只能人工点。
- 日志：优先 `%LOCALAPPDATA%\AirMouse\exe.log`，取不到就写 exe 同目录 `AirMouseServer.log`，再不行写 `%TEMP%`；启动第一行会打印实际路径。

**电脑端（源码版，需要 Python 3）**：

```powershell
cd pc
python airmouse_server.py              # 监听 0.0.0.0:47777
python airmouse_server.py --dry-run    # 只打印指令，不动真实鼠标（调试用）
```

或者直接双击 `pc\启动接收端.bat`（里面的窗口关掉就等于断开）。

**开机自启**（已经配好）：启动文件夹里放了一个快捷方式，登录 Windows 后自动在后台拉起来，没有黑框窗口，日志写到 `%LOCALAPPDATA%\AirMouse\server.log`。

- **登录后不是立刻起来？** Windows 会给「启动文件夹」里的程序加一段人为延迟（这台机器实测约 90 秒：
  21:47 登录、21:49 才起来）。已把 `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Serialize\StartupDelayInMSec`
  设成 `0`，之后再登录应该几秒内就起来。
- **怀疑没起来时**：双击 `pc\检查接收端.bat`，一次看到 进程 / 端口 47777 / 日志尾部 / 本机 IP。

- 想看服务端在收什么：`Get-Content "$env:LOCALAPPDATA\AirMouse\server.log" -Tail 20 -Wait`
- 不想自启：删掉 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\AirMouse 接收端.lnk`
- 手动起/停：`Stop-Process -Name pythonw`，或双击那个 .lnk 重新拉起

> 服务端不是常驻服务：电脑重启、关掉窗口、或者 Python 进程被结束，手机就会显示「正在连接…」并每 1.5 秒重试；服务端一回来就自动连上，不用在手机上重连。App 有独立的读线程，电脑端一断立刻能发现，不会假装还连着。
> 做「真正的 Windows 服务」（不登录也在跑）需要管理员权限装 NSSM 之类的包装器；当前是「登录后自启」，
> 日常够用，但无人值守的机器不合适（登录前、锁屏切换用户时不会有）。

启动后会打印本机 IP。**WiFi 模式**：

1. 连接方式选「WiFi」。
2. 第一次选「WiFi」会自动弹 IP 输入框（已经填过就只 toast 提示当前地址）；之后想改点状态栏即可。
3. 状态变绿，副标题写 `WiFi · 192.168.1.51:47777`。

**USB 模式**（只插数据线，不经过路由器，不用填任何 IP）：

1. 连接方式选「USB」。
2. 把右上角开关打开。
3. 电脑端每 3 秒扫一次 `adb devices`，发现插上的手机就自动执行 `adb reverse`，
   日志打 `[+] USB 通道已就绪 <序列号> -> 127.0.0.1:47777`；手机随即显示 `USB · 127.0.0.1:47777`。
4. 前提：手机开了「USB 调试」且这台电脑被授权过（`adb devices` 能看到它）。
5. 点状态栏会弹「USB 模式」说明，里面有「重连一次」按钮；排错时也可以手动执行
   `adb reverse tcp:47777 tcp:47777`。
6. 不想让服务端碰 adb：启动接收端时加 `--no-adb`。

> 2.2 之前是「一个 WiFi/USB 合并按钮 + 连不上自动退回 127.0.0.1」；2.2 拆成两个按钮，
> 2.3 又合并成一个下拉菜单（省地方）。WiFi 模式下就算插着线也只走 WiFi。

Windows 防火墙第一次可能会弹窗，允许 Python 访问专用网络即可。

## 四、界面怎么用

打开 App 先把右上角**开关打开**——这是总开关，关着时所有输入都不会发到电脑。

**设置（右上角「设置」）**：底部滑出一张抽屉，只有四行 —— 滚轮惯性（点 关/弱/中/强
直接选，不用循环点）、外观、使用说明、全部重置（会先问一句）。低频道具都搬到了用得着的地方：
电脑 IP 在选 WiFi 时当场填，打字方式在键盘面板顶部，蓝牙配对在连接方式下拉的最后一行
「配对新电脑…」。抽屉可下滑关闭，也能点右上角 ✕。

**外观（深色 / 浅色，v2.17 起）**：设置 → 外观，点一下按「跟随系统 → 浅色 → 深色」轮换，
选中立刻重建界面生效（不用重启 App）。跟随系统时跟着手机的深色模式走：系统切夜间，App 也跟着变。
两套配色不是简单反色：浅色下强调色换成更深的青（#0E7490，浅底上才看得清），卡片是白底浅描边，
触摸板是白到浅灰的渐变；深色保持原来的近黑底 + 亮青。
切换时会重建界面（不然颜色不换），但**总开关和陀螺仪模式会一起带过去**（v2.18 修）：
原来开着控电脑、用着射线的，切完外观还是开着、还是射线，也不会再弹一次「已启用」的提示。

**使用说明**（设置 → 使用说明）：也是同一款底部抽屉，五节（开机流程 / 触摸板 / 陀螺仪 /
键盘 / 小技巧），左边灰色是手势名、右边亮色是效果，两列对齐，长文可整屏滚动、底部渐隐收边。
它是**叠在设置抽屉上面**打开的，关掉（✕ 或返回键）就回到设置，不会一路退回主界面。

**所有窗口都是同一套**（v2.9 起）：设置、使用说明、全部重置、WiFi 填 IP、蓝牙设备列表、
手机输入法打字、射线校准 —— 全是「从底部滑出的圆角抽屉 + 圆角矩形拖柄 + 标题 + 内容 +
右下角文字按钮」，不再混用系统 AlertDialog 的灰底方框。

**横屏（v2.19 起）**：手机横过来会自动切到横屏布局 —— 左边一条控制栏（状态、连接方式、陀螺仪、
总开关、左/中/右键、键盘、灵敏度），右边整块触摸板 + 右侧滚轮条，两只手捧着用最顺。
横屏下键盘面板居中、键帽压矮一点（rows 46dp→37dp），五排正好放得下；
系统的手机输入法在横屏会浮在右侧，抽屉停在左下，互不遮挡。
横竖屏切换会重建界面，但总开关和陀螺仪模式会一起带过去（沿用 v2.18 的状态恢复）。

**横屏下陀螺仪只有「关」（v2.20 起）**：横过来就是「左手按键、右手拖触摸板」的姿势，
再叠一层陀螺仪既没地方瞄也不好放，所以横屏时陀螺仪下拉固定显示「陀螺仪 关 ▾」并变暗，
点它会提示「转回竖屏再开」，校准胶囊也一起隐藏。
竖屏里设的模式会被记下来：横屏期间只是「暂存」，转回竖屏后自动接回（v2.21 起）；
反过来，如果你在竖屏本来就把陀螺仪关着，横竖来回转也不会替你打开。

**触摸板**（中间大块）

| 手势 | 作用 |
|---|---|
| 单指拖动 | 移动光标 |
| 轻点 | 左键单击 |
| 长按后拖动 | 按住左键拖选 |
| 双指上下 | 滚轮 |
| 双指轻点 | 右键单击 |

- 触摸板**正上方中间那条竖向滚轮条**就是鼠标滚轮：上下滑动，一格一格滚（越滑越快）。
- 触摸板**正下方**一行是左键 / 中键 / 右键 / 键盘，按下即按住、松手即松开（可以按住拖动）。
  中键故意做窄一点（只用来开新标签/自动滚动），左右键更宽更好按。
- 布局照真实鼠标摆：滚轮在中间靠前，左右键在前下方。
- **手指按下去有光晕**：触点处一圈柔光 + 小圆点，抬手淡出；四角圆弧常驻，按下时变亮——
  不用猜「到底抓没抓到」。
- **开关关着的时候，跟控鼠标有关的东西全部禁用**：触摸板不响应手势（也不画触点光晕）、左中右键、键盘、灵敏度滑杆、以及陀螺仪下拉都点不动，整块界面会暗下去；这时去点任何一处都会提示「先把右上角的开关打开」（4 秒只提示一次），不会静默无反应。

**陀螺仪**（右上那个下拉：关 / 相对 / 射线）

> 之前是一个按钮轮流切（关→相对→射线→关），点两下才到射线、容易点过头；
> 2.3 起直接列成下拉菜单，选哪个就是哪个，一眼看到现在是什么状态。

- **要连着电脑才能开**（2.7 起）：陀螺仪是用来动光标的，没连接时下拉会压暗并提示「先连上电脑」；
  连接中途断了会自动切回「关」并 toast「连接断了，陀螺仪已暂停」。重新连上不会自己恢复，
  需要你再选一次——避免你人已经走开、手机还在那转手腕控鼠标。
- **开关关掉再打开会接回上次的模式**（2.15 起）：关总开关时记下当时开的是哪个，等重新启用并连上电脑后
  自动恢复（比如原来是「射线」，再打开还是「射线」）。但如果你在菜单里手动选了别的，就以手选为准。
- **相对**（下拉显示「陀螺仪 相对」）：左右转手腕光标左右走，抬/压手腕光标上下走；姿态无关，
  竖着拿、平着拿都会自动换算到「开启那一刻」的朝向；静止 0.6 秒自动学零偏。觉得漂了点「校准」。
- **射线**（下拉显示「陀螺仪 射线」）：把手机当激光笔——机头顶端就是射线，指向屏幕哪里，光标就
  落在射线与屏幕的交点上（真·绝对定位，不漂不累积）。
  此时滑杆变成**视场角**（±10°～±45°）：数值越小越灵敏，`±33°` 表示左右各转 33° 打到屏幕边缘。
  - 陀螺仪开着时，触摸板**右下角会出现「校准」**小胶囊（关了就自动消失，不占地方；2.16 起从右上角挪到右下角，单手拇指够得着）。
  - **「校准」单击 = 立刻对准中心**（最快：指到屏幕正中间按一下，当前朝向立刻变成中心）。
  - **「校准」长按 = 打开校准菜单**：
    - **对准屏幕中心**：同上，只是想从菜单里点。
    - **两点校准（左上角 + 右下角）**（最准）：先指显示器左上角按「采下」，再指右下角按「采下」。
      程序用这两次采样算出线性映射，把「视场角设得对不对」「你站得偏不偏」一起校正掉，
      光标和射线视觉落点基本重合。校准后滑杆旁显示 **两点 ✓**（此时视场角不再影响结果），
      想退回就在菜单里选「取消两点校准」。
    - 注意：两点校准只在本次运行有效，重启 App 要重新对准；点「对准屏幕中心」会清掉它（换了参考系）。
  - 这个模式下**触摸板直接当滚轮用**：单指上下滑就滚（竖条会收起来，不用再去够它），
    方向按「拖页面」的直觉——手指往上推页面往上走（页面内容往下滚）。轻点仍是左键、
    长按仍是按住左键拖动，光标完全由手机指向决定。
  - **甩一下会继续滚**：快速滑动后抬手，滚轮会按惯性继续减速滚动（像拨了一下真实滚轮），
    慢慢拖则停在哪算哪，不会乱飘。惯性强度在「设置 → 滚轮惯性」里直接点 **关 / 弱 / 中 / 强**
    （默认「中」，弱≈0.86、中≈0.92、强≈0.95 的每 16ms 衰减，越大滑得越远）。
- 灵敏度滑杆（相对模式）0.2×～2.5×，默认约 1.0×（约 480 像素/秒 每 1 rad/s）。
  两端标了「慢 / 快」，**点一下「灵敏度」三个字就回到默认**（1.0× / ±33°），懒得拖的时候用。
- 打开软键盘时会自动暂停陀螺仪，收起后恢复，避免打字时光标乱跑。
- 所有操作都可以在「设置 → 使用说明」里查一份图文字典（无需联网）。

> 射线模式用绝对坐标：蓝牙走 HID Report 3，网络模式走 `SendInput` 的绝对移动。
> 蓝牙下如果电脑只认出「相对鼠标」而没认出第三个集合，重新配对一次即可（Windows 会缓存旧描述符）。

**打字：两种方式，随时切**（键盘面板顶部两枚按钮）

| | 直通键码 | 手机输入法 |
|---|---|---|
| 怎么打 | 面板上的 QWERTY，一个键 = 一个真实按键 | 弹出一个输入框，用手机自己的输入法（拼音/手写/表情） |
| 电脑收到 | 逐字符的按键，光标跟着走 | 打好后**整段文字**一次注入 |
| 中文 | 不行（蓝牙协议只有键码） | 网络模式可以 |
| 适合 | 敲命令、快捷键、英文密码 | 聊天、填表、任何要中文的场合 |

- 直通键码：字母页/符号页可切，⇧ Ctrl Alt 是一次性修饰键（下一个键生效）。
- **默认是手机输入法**（2.11 起）：点「键盘」按钮，面板和系统输入法一起出来，打好字点「发送」，
  文字发出去的同时键盘面板和输入法都收起，回到触摸板。
- 想敲按键就点面板上的「直通键码」tab，切过去之后不会再自动弹输入法（App 记住你上次选的）。
- 键盘面板是浮层（2.13 起）：从底部盖上来、背后压一层暗色，触摸板和按键尺寸不变；点面板以外的暗色处就收起。
- 蓝牙模式下非英文字符会被跳过并弹提示，中文请切 WiFi 或 USB。

> 为什么中文只能走网络模式：蓝牙 HID 键盘协议里只有「按了哪个键」的键码，没有传输任意文字的通道。网络模式在电脑侧用 `SendInput` + `KEYEVENTF_UNICODE`，才能把中文原样注入。

## 六、已知限制 / 踩过的坑

- **HID 模式打不了中文**：蓝牙键盘协议只送键码，中文必须走网络模式（服务端用 `KEYEVENTF_UNICODE`）。
- **小米/HyperOS 拦 adb 安装**：`adb install` 报 `INSTALL_FAILED_USER_RESTRICTED` 时，要么在开发者选项里打开「USB 安装管理」，要么直接把 APK 拷进手机用文件管理器点安装。
- **`adb shell input` 在 HyperOS 上会被静默丢掉**：不报错，但界面毫无反应（`mCurrentFocus` 还是本 App）。想在红米/小米上做自动化点击验证是做不了的，只能人工点，或者用下面的 `--ez` 调试开关绕过界面。
- **蓝牙绝对指针要「配对时就带着 HID 服务」**：Windows 会缓存配对当时的 HID 描述符。正确做法是 App 停在「蓝牙 HID / HID 就绪」时再配对——扫描列表里看到的是手机蓝牙名（如 `Redmi K70`），`AirMouse-xxx` 是 HID 服务名，配对成功后才出现。配对错了会变成「普通手机」，此时删掉重配即可；WiFi 模式的绝对定位不受影响。
- **targetSdk 36 强制全面屏**：界面已用 `WindowInsets` 自己加内边距，适配状态栏/手势条。
- **离线构建**：`gradle.properties` 里的 `android.suppressUnsupportedCompileSdk=36` 是因为 AGP 8.7.3 只认证到 35；`local-repo` 里补了缓存缺失的 `kotlin-reflect:2.0.21`。

## 六点五、出问题怎么取日志

- **手机**：设置 → 诊断日志 → 复制 / 保存到文件（存到「下载」，形如 `airmouse-log-20261107-130421.txt`）。记录：App 版本、机型系统、开关与连接方式、连接成功/失败原因、HID 注册与连接状态、陀螺仪/射线开关、发送文字字数；**不含鼠标坐标、不含输入内容**。
- **电脑**：接收端窗口右下角「查看日志」（记事本打开并复制路径）。文件优先级：`%LOCALAPPDATA%\AirMouse\exe.log` → exe 同目录 `AirMouseServer.log` → `%TEMP%\AirMouseServer.log`；窗口第一行日志会打印实际路径。
- 让用户复现前先「清空」，导出的日志最短最有用。
