# 生活图谱 · 多端通用的人物/事物关系可视化

记录生活中人物、事物之间关系的本地图谱网页。

- **零依赖**：只有原生 Node.js 和浏览器，不需要 `npm install`，不需要构建。
- **多端通用**：服务监听局域网，手机、平板、电脑用浏览器打开同一地址即可看图、编辑，所有设备实时同步。
- **数据是普通 md 文件**：存在服务端数据目录里，可读可备份；关系写在每个节点自己的文件里。
- **两种节点模式**：一个文件 = 一个节点；或一个文件里用章节标记放多个节点。

## 快速开始

**最省事**：双击项目根目录的 `启动生活图谱.bat`（Windows），服务启动后会自动打开浏览器。

命令行方式：

```bash
node server.js            # 默认数据目录 ./data，端口 8899
node server.js mynotes --port=8899    # 指定数据目录 / 端口
node server.js --open     # 启动后自动打开浏览器
```

启动后访问（端口若被占用会自动顺延，以窗口打印为准）：

- 本机：`http://127.0.0.1:8899`
- 手机/平板（同一 Wi-Fi）：`http://<电脑局域网IP>:8899`（Windows 首次运行防火墙弹窗请允许「专用网络」）

> 浏览器页面只是查看/编辑工具，**数据永远在 md 文件里**，删掉网页也不影响数据。

## 数据语法（普通 md）

### 文件即节点（File-Node）

每个实体一个文件，文件名就是节点 id（建议用英文/数字/下划线，无空格）。

`data/tang.md`：

```md
# 唐永强
#person #hobby:badminton

> 备注：1999年生，常驻南昌，喜欢折腾数码。

## 关联
->[拥有] zk007gt
->[朋友] liuwei
```

- `# 标题`：显示名（没有则用文件名）
- `#tag`：标签，正文任意位置（支持 `#hobby:badminton` 这类带值标签）
- `> 备注：...`：备注（连续引用行合并）
- `## 关联` / `## 关系` 块内：
  - `->[关系] 目标id` —— 出边
  - `<->[关系] 目标id` —— 显式双向
  - `-> 目标id` —— 缺省关系名「关联」
- 关系只需要写在 A 这边；B 文件不用反向写。

### 章节节点（Section-Node）

一个文件放多个节点，用标记切分（适合「同学录」「收藏清单」这类零散实体）：

`data/contacts.md`：

```md
%%@node:alice::爱丽丝%%
# 爱丽丝
#person

> 备注：大学同学。

## 关联
->[朋友] bob

%%@node:bob::鲍勃%%
# 鲍勃
#person
```

规则：文件里出现任意 `%%@node:id::显示名%%` 标记，则该文件只解析为章节节点集合（不再生成文件级节点）。

### 样式与双向关系配置（`graph-config.md`）

```md
//!style
#person:color=#60a5fa,shape=ellipse
#hobby:*:color=#e879f9,shape=ellipse

//!bidir:朋友,同事,认识
```

- 形状支持：`ellipse`（默认）/ `circle` / `rectangle` / `diamond` / `rounded`
- `#hobby:*` 匹配所有 `#hobby:xxx` 标签
- `//!bidir:all` = 所有关系自动生成反向边
- 自动反向边在图上显示为**虚线**

## 网页功能

- 力导向布局，节点可拖拽、滚轮缩放、空白拖拽平移、双击空白复位
- 单击节点：详情面板（标签、备注、出入关系，点关系可跳转）
- 双击节点：直接编辑该节点的 md 文件（保存后所有设备同步）
- `+ 新建`：创建独立文件节点，或向现有文件追加章节节点
- 搜索框：按名字 / id / 标签过滤高亮
- 顶栏标签 chips：按标签筛选
- 红色虚线框节点：被别处引用但还没有内容的「幽灵节点」，点击即可补建
- `↻` 重新布局、`?` 图例与语法帮助、`↓` 导出图谱 JSON
- 文件被外部（比如另一台设备）修改时，页面实时自动刷新

## 项目结构

```
├─ server.js          # 本地服务：API + SSE + 文件监听 + 静态托管
├─ lib/parser.js      # md 解析器（纯逻辑，可单独复用）
├─ public/            # 前端（原生 HTML/CSS/JS，Canvas 渲染）
│   ├─ index.html
│   ├─ style.css
│   └─ app.js
├─ data/              # 默认数据目录（示例内容，可直接改）
└─ README.md
```

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/graph` | 图谱数据（节点/关系/样式/警告），实时解析 |
| GET | `/api/files` | 文件列表 |
| GET | `/api/file?id=x` | 读取 md 原文 |
| PUT | `/api/file` | 写入/新建 md（`{id, content}`） |
| POST | `/api/section` | 向文件追加章节节点（`{file,id,name,tags,note}`） |
| GET | `/api/events` | SSE 实时变更推送 |
| GET | `/api/health` | 健康检查 |

## 小贴士

- 想要分主题的数据？启动多个服务实例，各指一个数据目录即可。
- 数据目录允许包含子目录（会被递归监听），解析器也会读子目录里的 md（节点 id 为文件名）。
- 建议定期把 `data/` 复制一份做备份。
- 仅信任的局域网使用；如需公网访问，请自行加反向代理与鉴权。
